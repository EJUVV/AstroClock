# CLAUDE.md

Leia e siga o [`AGENTS.md`](AGENTS.md). Ele contém as regras deste projeto para qualquer assistente de IA.

Antes de qualquer tarefa, consulte também:
- [`docs/regras-de-negocio.md`](docs/regras-de-negocio.md) — regras do sistema (nunca invente regras)
- [`docs/arquitetura.md`](docs/arquitetura.md) — camadas, banco e contrato das funções de dados
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — branches, commits e PRs

Se a tarefa for a configuração inicial do projeto, siga [`docs/fase-0.md`](docs/fase-0.md).

Preferência do líder do projeto: **faça perguntas antes de assumir qualquer coisa**, principalmente sobre regra de negócio, e mostre um plano curto antes de escrever código.
